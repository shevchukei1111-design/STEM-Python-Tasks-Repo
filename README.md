# STEM-Python-Tasks-Repo
Репозиторій задач з програмування для STEM
Відкритий навчальний репозиторій прикладних задач з програмування на мові Python для учнів 10–11 класів (Варіант № 9).

## Структура репозиторію
- `data/` — знеособлені набори експериментальних даних (`.csv`)
- `src/` — шаблонні скрипти та приклади розв'язання задач (`task_01_kinematics.py`, `task_02_climate.py`)
- `tests/` — модульні тести (`pytest`) для самоперевірки
- `docs/` — методичні рекомендації та схема алгоритму обробки даних
- `LICENSE` — умови відкритого ліцензування (MIT License)
